Data deletion and data handling

Last updated: 5 September 2026

There is no account to delete and no server to write to. MovieClipsFactory stores everything on the computer it runs on. Deleting your data means deleting it there, and revoking the application's access on each platform. Both are described below, and neither requires anyone's cooperation.

1. Disconnect an account inside the application

On the Social networks screen, choose the account and select Disconnect. The stored token is removed from the Windows vault immediately, and the application calls the platform's revocation endpoint where one exists.

2. Revoke access on the platform itself

This is the authoritative step, and it works whether or not the application is still installed:

PlatformWhere to revoke
YouTube / Google Google Account → Security → Your connections to third-party apps
TikTok TikTok app → Settings and privacy → Security and permissions → Manage app permissions
Instagram Instagram → Settings → Website permissions → Apps and websites
Facebook Facebook → Settings & privacy → Settings → Apps and websites

3. Delete everything on the computer

Deleting the application's folder removes the local database, the imported videos, the rendered clips, the logs and the encrypted token vault. There is no copy anywhere else, because there is nowhere else.

4. What is deleted, and what is not

DataWhere it livesHow it is deleted
Access tokensencrypted vault (Windows DPAPI), on the computerdisconnecting the account, or deleting the folder
Videos, clips, captions, audiothe application's folder deleting the folder
Projects, clips, historylocal SQLite database deleting the folder
A clip already published to a networkthat network delete it in that network's own app — the application cannot reach it once it is there

5. A request by e-mail

There is no database on our side to search, so a deletion request has nothing to act on. If something here is unclear, or a platform asks for a deletion contact, write to vidotofernandes@gmail.com and it will be answered.

MovieClipsFactory is a personal desktop application. It is not a company and not a hosted service.
