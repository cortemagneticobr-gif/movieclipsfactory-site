MovieClipsFactory

A desktop application that turns long videos into vertical clips — and, when its operator asks, sends those clips to their own social accounts.

MovieClipsFactory runs on the computer of the person using it. There is no MovieClipsFactory server, no MovieClipsFactory account, and no subscription. Nothing about the person who uses it is sent anywhere by default.

What it does

  • Imports a long video and detects its scenes.
  • Transcribes the dialogue and picks candidate moments.
  • Renders 9:16 clips with burned-in captions and, optionally, narration.
  • Scores each clip for technical and editorial quality, and refuses the ones that do not pass.
  • Uploads an approved clip to YouTube, TikTok, Instagram or Facebook through each platform's official API, using the operator's own authorised account.

What it is not

It is not a hosted service and not a multi-user product. There is no sign-up, no server that holds anyone's data, and no version of this that other people log into. It is a program someone installs and runs.

This matters for platform review, so it is stated plainly rather than dressed up. TikTok's Content Sharing Guidelines list, among unacceptable use cases:

"A utility tool to help upload contents to the account(s) you or your team manages. ❌"

MovieClipsFactory is exactly that kind of tool, so it is not eligible for audited Content Posting API access on TikTok. It therefore uses the unaudited path: video.upload, which places the video in the creator's TikTok inbox as a draft for that person to finish and post inside the TikTok app. It does not claim otherwise in order to pass a review.

How it treats accounts and credentials

  • Accounts are connected by the platform's own OAuth screen. The application never sees or asks for a password.
  • Access tokens are stored encrypted by the Windows DPAPI on that computer. They are never written in plain text, never logged and never committed to source control.
  • Publishing is off by default, and public posting is a second, separate switch that is also off by default.
  • A rights gate blocks any publication that has not been explicitly declared as material the operator has the right to use.
